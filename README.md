📊 Vendor Purchase Analysis – Power BI Project
🧾 Project Overview

The Vendor Purchase Analysis project focuses on analyzing vendor procurement data to uncover insights related to vendor performance, purchasing behavior, payment patterns, and cost efficiency.
In addition to dashboard-based analytics, the project applies statistical hypothesis testing to validate business assumptions using data.

This project demonstrates a complete data analytics lifecycle: data cleaning, modeling, statistical analysis, and interactive visualization.

🎯 Objectives

Analyze vendor-wise purchase and payment trends

Identify high- and low-performing vendors

Track procurement KPIs

Validate business assumptions using hypothesis testing

Improve reporting efficiency through automation

🛠️ Tools & Technologies Used

Power BI – Data modeling, DAX measures, dashboards

SQL – Data extraction, joins, aggregations

Excel – Data validation and exploratory analysis

Python – Data preprocessing and statistical analysis

Statistics – Hypothesis testing and inference

📂 Dataset Description

The dataset includes:

Vendor details

Purchase orders

Transaction amounts

Payment dates

Quantity and cost-related fields

The data was consolidated from multiple structured sources for analysis.

🔄 Data Preparation & Cleaning

Removed duplicates and handled missing values

Standardized date and numeric formats

Merged vendor, purchase, and payment datasets

Created derived metrics for analysis

📐 Data Modeling

Designed a structured data model for efficient reporting

Established relationships between vendor and transaction tables

Optimized model performance for analytical queries

📊 Key KPIs & Metrics

Total Purchase Amount

Vendor-wise Spend

Number of Purchase Orders

Average Purchase Value

Payment Trends Over Time

📐 Hypothesis Testing (Statistical Analysis)

To support data-driven decision-making, hypothesis testing was applied to validate business assumptions.

Examples of Hypotheses Tested:

H₀ (Null Hypothesis): There is no significant difference in average purchase value across vendors

H₁ (Alternative Hypothesis): Certain vendors have significantly different average purchase values

Statistical Techniques Used:

Formulated null and alternative hypotheses

Selected appropriate significance levels (α)

Performed statistical tests (e.g., t-test / ANOVA where applicable)

Interpreted p-values to accept or reject hypotheses

📌 This ensured that insights derived from the dashboard were statistically validated, not just visually inferred.

Analyze purchasing and payment trends over time

Support statistically validated business decisions
